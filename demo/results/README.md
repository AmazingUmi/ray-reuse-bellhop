# 展示结果分类

```text
results/
├── reliability/
│   ├── origin/
│   ├── f2cpp/
│   ├── rayreuse/
│   └── run_summary.json
└── rayreuse_multifrequency/
    ├── munk_rayreuse_multifrequency.env
    ├── munk_rayreuse_multifrequency.prt
    ├── munk_rayreuse_multifrequency.shd
    └── run_summary.json
```

- `reliability/`：同一个单频环境的三版本直接运行和一致性验证结果；
- `rayreuse_multifrequency/`：RayReuse 一次运行产生的多频结果。

除本文档外，所有内容均为可再生成文件，不进入 Git。
