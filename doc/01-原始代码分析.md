# 01 Bellhop 原始代码分析

## 1. 分析范围

当前项目主要由以下部分组成：

```text
Bellhop/     Bellhop 2D/3D 主程序、声线积分、边界反射、波束影响计算
misc/        环境输入、频率向量、衰减、SHD 文件等公共模块
plotshd/     MATLAB SHD 读取和绘图脚本
test/        单频/多频环境文件、已有可执行文件及示例输出
Makefile     项目构建配置
```

本文以二维入口 `Bellhop/bellhop.f90` 为主，同时检查与宽带计算相关的公共模块。

## 2. 二维程序主流程

程序入口位于 `Bellhop/bellhop.f90`，主要流程如下：

```text
读取 .env
  -> 读取边界、SSP、收发位置、频率和波束配置
  -> 打开 .ray/.arr/.shd 输出
  -> BellhopCore
       -> 遍历源深度
       -> 遍历发射角
       -> TraceRay2D
       -> Influence*
       -> ScalePressure
       -> 写入输出文件
```

关键调用位置：

- `ReadEnvironment`：`Bellhop/bellhop.f90:133`
- `OpenOutputFiles`：`Bellhop/bellhop.f90:146`
- `BellhopCore`：`Bellhop/bellhop.f90:147`
- `TraceRay2D`：`Bellhop/bellhop.f90:288`
- `Influence*`：`Bellhop/bellhop.f90:297-314`
- `ScalePressure`：`Bellhop/bellhop.f90:324`
- `TraceRay2D` 实现：`Bellhop/bellhop.f90:431-592`

## 3. 主要模块职责

| 文件/模块 | 职责 | 与宽带改造的关系 |
|---|---|---|
| `Bellhop/bellhopMod.f90` | 全局 Bellhop 状态、波束和声线数据类型 | 当前只有标量 `freq/omega`，需要明确频率上下文 |
| `Bellhop/bellhop.f90` | 二维主循环、声线追踪入口、场量输出 | 主要改造位置 |
| `Bellhop/Step.f90` | 二维声线积分，更新 `x/t/p/q/tau` | 几何状态与复传播时间需要解耦 |
| `Bellhop/ReflectMod.f90` | 二维边界反射、反射系数、曲率修正 | 几何反射可复用，幅相损失需逐频重算 |
| `Bellhop/influence.f90` | 将一条声线/波束累加到接收场 | 必须对每个频率执行 |
| `Bellhop/sspMod.f90` | Bellhop 专用 SSP 及其导数计算 | 需要保留原始衰减数据并支持逐频更新 |
| `Bellhop/ReadEnvironmentBell.f90` | Bellhop 环境和输出文件配置 | 宽带选项尚未完整接通 |
| `misc/SourceReceiverPositions.f90` | 收发位置与 `freqVec` 读取 | 已具备宽带频率向量输入 |
| `misc/RWSHDFile.f90` | SHD 头部和记录写入 | 已支持多频头部，核心记录索引仍需调用方配合 |
| `misc/AttenMod.f90` | 不同衰减单位到复声速的转换 | 逐频重算吸收的基础 |

## 4. 当前声线数据结构

`Bellhop/bellhopMod.f90` 中的二维声线点为：

```fortran
TYPE ray2DPt
   INTEGER            :: NumTopBnc, NumBotBnc
   REAL    ( KIND=8 ) :: x( 2 ), t( 2 ), p( 2 ), q( 2 ), c, Amp, Phase
   COMPLEX ( KIND=8 ) :: tau
END TYPE ray2DPt
```

字段可以分为三组：

| 类别 | 字段 | 说明 |
|---|---|---|
| 几何状态 | `x`, `t`, `c` | 位置、慢度方向和实声速 |
| 动力学声线状态 | `p`, `q` | 几何扩展、焦散和波束传播所需状态 |
| 频率相关状态 | `Amp`, `Phase`, `tau` 的虚部 | 吸收、反射幅相及复传播时间 |
| 事件信息 | `NumTopBnc`, `NumBotBnc` | 只记录累计次数，不能完整描述反射事件 |

当前结构把可复用状态和逐频状态混在同一个数组中，是实施宽带复用时最需要处理的耦合。

## 5. 频率在当前代码中的传播

### 5.1 全局标量频率

`Bellhop/bellhopMod.f90:11` 定义：

```fortran
REAL (KIND=8) :: freq, omega
```

`BellhopCore` 在 `Bellhop/bellhop.f90:168` 计算：

```fortran
omega = 2.0 * pi * freq
```

后续 Step、Reflect、Influence 等模块直接读取这两个全局变量。因此当前代码没有显式的“当前频率参数”边界，也不利于测试单个子过程。

### 5.2 多频向量输入

`misc/SourceReceiverPositions.f90:38-76` 已实现：

- 从环境文件读取 `Nfreq`；
- 分配 `freqVec`；
- 使用 `SubTab` 展开首尾频率；
- 非宽带情况下将标量频率放入 `freqVec(1)`。

但是 `BellhopCore` 没有 `ifreq` 循环，计算仍使用标量 `freq`。

### 5.3 SHD 多频头部

`misc/RWSHDFile.f90:100-106` 会把 `Nfreq` 和 `freqVec` 写入 SHD 头部。不过当前二维主程序输出时使用：

```fortran
IRec = 10 + NRz_per_range * ( is - 1 )
```

记录号没有频率维度，因而当前源码不能完整写出多频压力场。

## 6. 哪些计算可以跨频复用

### 6.1 声线几何

`Bellhop/Step.f90` 使用实声速 `c` 和梯度推进：

```fortran
ray2%x = ...
ray2%t = ...
ray2%p = ...
ray2%q = ...
```

`CRCI` 将衰减表示为复声速的虚部，实部仍使用输入声速。因此在没有实声速色散时，以下量与频率无关：

- 轨迹位置 `x`；
- 射线方向/慢度 `t`；
- 动力学量 `p/q`；
- 边界交点及几何反射方向；
- 由实声速得到的几何传播时间。

### 6.2 反射几何和曲率修正

`Bellhop/ReflectMod.f90:166-208` 的曲率修正依赖边界曲率、入射方向、实声速及其梯度。在未启用频率相关 beam shift 时，这部分可以随几何轨迹一起复用。

## 7. 哪些计算必须逐频重算

### 7.1 水体传播损失

`Bellhop/Step.f90:79` 使用复声速积分 `tau`。`cimag` 可能由以下模型决定：

- dB/m、dB/波长、Q 或 loss parameter；
- Thorp；
- Francois-Garrison；
- 生物衰减。

这些模型具有不同的频率关系，不能直接复用某一个参考频率的复 `tau`。

### 7.2 边界反射幅度和相位

`Bellhop/ReflectMod.f90:63-108` 使用 `omega`、海底复声速和入射慢度计算反射系数。即使反射点和入射角相同，反射幅度及相位仍可能随频率变化。

### 7.3 波束影响

`Bellhop/influence.f90` 中的以下内容显式依赖频率：

- `omega * tau` 相位；
- 波束窗口；
- 波束半径和波长；
- Cerveny 波束的复参数 `epsilon`；
- 相干、半相干或非相干叠加；
- 最终压力缩放。

因此轨迹复用不会消除逐频 Influence 计算。

### 7.4 半相干源项

`Bellhop/bellhop.f90:278-280` 的 Lloyd mirror 源项直接包含 `omega`，必须逐频计算初始幅度。

### 7.5 按幅度提前终止

`Bellhop/bellhop.f90:574-578` 在 `Amp < 0.005` 时终止声线。由于 `Amp` 随频率变化，该条件会让不同频率产生不同长度的轨迹。

复用模式下应将几何轨迹继续追踪到空间边界，同时为每个频率维护“有效终止点”或 active mask，以模拟原单频逻辑。

## 8. Beam shift 是严格复用的例外

`Bellhop/ReflectMod.f90:122-156` 的 beam shift 会根据波数改变：

- 反射后的空间位置；
- 传播时间；
- `q`，即波束宽度状态。

此时几何轨迹本身已经带有频率依赖。第一版复用实现应拒绝 `Beam%Type(4:4) == 'S'`，而不是静默给出近似结果。

## 9. 已发现的源码与制品不一致

### 9.1 宽带选项不一致

测试环境使用第六个 SSP 选项字符 `B` 表示宽带。但当前 `Bellhop/ReadEnvironmentBell.f90:333-339` 只接受 `I` 和空格，按当前源码编译后会报错。

### 9.2 可执行文件与源码不一致

`test/bellhop.exe` 包含以下当前源码中不存在的行为：

- 输出 `Broadband calculation enabled`；
- 按 `NRz * NRr * Nfreq` 分配压力场；
- 生成完整多频 SHD 记录。

示例 SHD 文件大小对应 12874 条记录，恰好为：

```text
10 个头记录 + 64 个频率 × 201 个接收深度
```

因此该二进制可能来自另一份未提交源码或不同版本的 Acoustic Toolbox。

### 9.3 两套同名 SSP 模块

项目同时存在：

- `Bellhop/sspMod.f90`；
- `misc/sspMod.f90`。

Bellhop Makefile 显式编译前者。后者虽然有 `UpdateSSPLoss` 和 `UpdateHSLoss`，但不能假定这些过程会被 Bellhop 链接使用。宽带能力应实现到 Bellhop 自己的 SSP 模块中，或先统一模块来源。

### 9.4 原始衰减数据丢失

`Bellhop/sspMod.f90:877-881` 读入 `alphaI` 后立即通过 `CRCI` 转换成复声速，却没有逐深度保存原始 `alphaR/alphaI`。这使得后续无法根据另一个频率准确重建复声速。

## 10. 性能边界

原始逐频独立计算复杂度可近似写成：

```text
Nfreq × Nray × (TraceCost + InfluenceCost)
```

轨迹复用后为：

```text
Nray × TraceCost
+ Nfreq × Nray × (ReweightCost + InfluenceCost)
```

所以：

- 声线积分占比越高，收益越明显；
- 接收网格很大时，Influence 可能成为主要耗时；
- 加速比一般小于 `Nfreq`；
- 仍应对 `TraceRay`、频率重着色和 Influence 分别计时。

## 11. 当前分析结论

二维 Bellhop 可以实现精确意义上的几何轨迹复用，但需要先解决以下四个核心问题：

1. 将几何状态与频率相关的幅相/吸收状态分离；
2. 保留 SSP 和半空间的原始衰减参数；
3. 显式记录边界反射事件；
4. 将主循环和 SHD 输出扩展为真正的频率维度。

## 12. 面向 C++ 重构的模式裁剪

原 Bellhop 通过 `RunType` 和 `Beam%Type` 将大量模式集中在同一套全局状态和分支中。新的 C++ 实现不需要逐项翻译这些分支，而应只抽取宽带声场主链路。

首版保留矩阵：

| 原版维度 | 首版 C++ 选择 | 处理方式 |
|---|---|---|
| `RunType(1:1)` | `C` coherent TL | 唯一声场模式 |
| `RunType(2:2)` | `C` Cartesian Cerveny | 唯一波束模式 |
| `RunType(4:4)` | 点源/原测试所需形式 | 固化为配置，不保留通用分派 |
| `RunType(5:5)` | rectilinear | 不实现 irregular grid |
| 空间维度 | 2D | 不编译 3D 路径 |
| 场分量 | pressure | 不实现水平/垂直速度分量 |
| 输出 | broadband SHD | 不实现 ray/eigenray/arrival 输出 |

以下原代码仍是行为参考核心：

- `Step.f90`：中心射线与动态射线积分；
- `ReflectMod.f90`：边界交点、几何反射和反射系数；
- `influence.f90`：Cartesian Cerveny 波束对接收场的贡献；
- `sspMod.f90`：声速及一、二阶导数；
- `RWSHDFile.f90`：SHD 布局。

其余模式应视为范围外参考，避免把原版全局变量、文件单元号和模式分支机械搬进 C++。
