## 当前结论

项目目标已收敛为：参考原 Bellhop 数值行为，构建二维宽带相干声场计算；环境、收发位置和发射角集合在一次运行中固定，只追踪一次几何声线，再对多个频率重算损失、反射、波束宽度和复压力。

C++ 是当前推荐实现语言，但理由是便于构造不可变环境、线程局部声线状态、频率所有权明确的压力场和后续性能工程，而不是 C++ 标量计算天然快于 Fortran。最终采用决定受 `04` 文档中的性能门槛约束。

在实声速和环境几何不随频率变化、且未启用 beam shift 的前提下，几何声线状态 `x/t/p/q` 可以跨频率复用。传播吸收、边界反射系数、波束参数及最终声场贡献仍需逐频计算。

当前仓库具备多频输入和 SHD 头部输出的部分基础设施，但 `Bellhop/bellhop.f90` 的核心计算仍是单频结构。`test/bellhop.exe` 表现出的宽带能力与当前源码不一致，不能把该二进制视为当前源码的可重现构建结果。

## 建议实施范围

第一阶段不追求重写原 Bellhop 的所有运行模式，只保留：

1. 二维、固定环境、固定收发位置；
2. 多频 coherent TL；
3. Cartesian Cerveny 波束（对应原版 `CC` 路径）；
4. rectilinear 接收网格和压力分量；
5. SHD 输出及逐频单跑回归。

`R/E/I/S/A/a`、3D、arrivals、eigenray、beam shift 等模式不进入首版 C++ 范围。
