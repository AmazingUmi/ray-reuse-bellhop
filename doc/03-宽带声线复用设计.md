# 03 Bellhop 宽带声线复用设计

> 当前实现目标为二维宽带 coherent TL 程序，而不是继续保留原 Fortran 的全部运行模式。本文描述算法边界；语言选择、并行结构和采用门槛见 [04 C++ 重构方案与性能决策](./04-C++重构方案与性能决策.md)。

推荐的无竞争 CPU 并行顺序是“发射角分批缓存几何轨迹，再并行处理频率”。同一工作线程独占一个频率对应的压力场切片，因此无需对复压力累加使用原子操作。

## 1. 设计目标

对于同一环境、源位置和发射角集合：

- 几何声线只追踪一次；
- 对 `freqVec` 中每个频率重新计算损失、反射、波束参数和压力场；
- 输出标准多频 SHD 文件；
- 在支持的物理选项下，与逐频独立单频运行保持数值一致；
- 保留原单频运行方式，便于回归和故障定位。

第一阶段仅覆盖二维 coherent TL 和 Cartesian Cerveny 波束。semi-coherent、incoherent、arrivals、eigenray 和 3D 不在当前产品目标内；除非需求重新扩大，不安排兼容实现。

## 2. 支持边界

### 2.1 第一阶段支持

- 二维 Bellhop；
- 实声速不随频率变化；
- 固定海面和海底几何；
- C-linear、N2-linear 等现有 SSP；
- 真空、刚性和声学半空间边界；
- 水体频率相关吸收；
- Cartesian/Ray-centered Cerveny 波束中的一个优先实现类型；
- rectilinear 接收网格；
- coherent TL 与 SHD 输出。

### 2.2 第一阶段显式不支持

- beam shift；
- 实声速色散；
- 不同频率采用不同发射角集合；
- 频率相关边界几何；
- Bellhop3D；
- 多频 arrivals 文件格式；
- 频率相关源波束图的新输入格式。

不支持条件应在读取配置或进入核心计算前报错，不能自动退化为未经说明的近似。

## 3. 推荐数据模型

### 3.1 几何声线点

建议在 C++ 中定义为：

```cpp
struct RayGeometryPoint {
    Vec2 position;
    Vec2 slowness;
    std::array<double, 2> p;
    std::array<double, 2> q;
    double soundSpeed;
    double travelTime;
};
```

`travelTime` 使用实声速积分，不包含吸收。

为了降低第一版改动量，也可以继续使用 `ray2D` 保存几何量，但必须明确：几何追踪完成后，其中的 `Amp/Phase/complex tau` 不再作为跨频复用的权威状态。

### 3.2 反射事件

建议显式记录：

```cpp
struct ReflectionEvent {
    std::size_t rayPointIndex;
    BoundaryKind boundary;
    std::size_t boundarySegment;
    double tangentSlowness;
    double normalSlowness;
};
```

显式事件比通过 `NumTopBnc/NumBotBnc` 反推更可靠，特别是距离相关半空间参数和反射点重复存储的情况下。

### 3.3 单频声线状态

可复用一个工作数组，而不必为每条声线永久保存所有频率状态：

```cpp
struct RayFrequencyPoint {
    std::complex<double> travelTime;
    double amplitude;
    double phase;
    bool active;
};
```

处理一个频率时，由几何轨迹和反射事件生成该数组，然后立即调用 Influence。

## 4. 核心过程拆分

### 4.1 几何追踪

建议 C++ 接口：

```cpp
RayPath GeometryTracer::trace(const Source& source, double launchAngle) const;
```

职责：

- 初始化 `x/t/p/q`；
- 按实声速推进；
- 处理边界交点和几何反射；
- 记录反射事件；
- 追踪到空间盒边界或几何数值异常；
- 不使用频率相关幅度作为终止条件。

### 4.2 频率状态构造

建议 C++ 接口：

```cpp
RayFrequencyState FrequencyProjector::project(
    const RayPath& path, double frequency, double sourceAmplitude) const;
```

职责：

1. 根据当前频率更新 SSP 和半空间复声速；
2. 沿几何轨迹重新积分复传播时间；
3. 在反射点计算对应频率的反射系数；
4. 累计 `Amp/Phase`；
5. 根据原单频规则维护 active mask；
6. 将结果提供给 Influence。

复传播时间应使用与 Step 相同的二阶积分权重，以减少与独立单频运行之间的数值差异。

### 4.3 Influence 接口

C++ 版本不继承 Fortran 的全局 `ray2D` 写回方式。Influence 应显式接收只读几何轨迹和逐频状态：

```cpp
influence.accumulate(field.at(frequencyIndex), path, frequencyState,
                     frequency, epsilon);
```

这样可在类型层面阻止一个频率污染另一个频率的状态。

## 5. 主循环设计

推荐采用逐射线流式复用，不把全部射线永久缓存：

```cpp
BroadbandField field(grid, frequencies);
for (double launchAngle : launchAngles) {
    RayPath path = tracer.trace(source, launchAngle);
    for (std::size_t fi = 0; fi < frequencies.size(); ++fi) {
        auto state = projector.project(path, frequencies[fi], sourceAmplitude);
        influence.accumulate(field[fi], path, state, frequencies[fi]);
    }
} // path 在这里释放

field.scale();
shdWriter.write(field);
```

发射角数量和相关默认参数应按 `MAXVAL(freqVec)` 选择，以满足最高频率的空间采样要求。

## 6. 压力场内存布局

直接方案：

```fortran
COMPLEX, ALLOCATABLE :: U(:, :, :)
ALLOCATE(U(NRz_per_range, Pos%NRr, Nfreq))
```

示例 `201 × 501 × 64` 的单精度复数压力约占 51.6 MB，可接受。

如果未来内存过大，可增加频率分块：

```text
每批 K 个频率：追踪一次全部声线，累加 K 个频率，再写出
```

这种方法每个频率批次仍需重新追踪一遍，因此属于内存与复用率之间的折中。

## 7. SHD 输出记录布局

二维 rectilinear 输出的记录号应包含频率和源深度维度：

```fortran
IRec = 10 + Irz1 + NRz_per_range * &
       ( ( is - 1 ) + Pos%NSz * ( ifreq - 1 ) )
```

写出前需要确认其顺序与 `read_shd.m` 以及 Acoustic Toolbox 标准一致。

建议封装过程：

```fortran
INTEGER FUNCTION SHDRecord2D(ifreq, isz, irz)
```

这样可以集中测试索引，避免在多个入口复制公式。

## 8. SSP 与半空间更新设计

### 8.1 保存原始数据

Bellhop 专用 `SSPStructure` 应保存逐节点原始数据：

```fortran
REAL(KIND=8) :: alphaR(MaxSSP)
REAL(KIND=8) :: alphaI(MaxSSP)
REAL(KIND=8) :: betaR(MaxSSP)
REAL(KIND=8) :: betaI(MaxSSP)
```

读入时保存原始值，然后由当前频率生成 `SSP%c` 和插值系数。

### 8.2 更新接口

建议在 C++ 的不可变 `SoundSpeedProfile` 中保留原始参数，并提供：

```cpp
SoundSpeedSample SoundSpeedProfile::evaluate(Vec2 x) const;
double SoundSpeedProfile::imaginarySpeed(Vec2 x, double frequency) const;
HalfspaceSample BoundaryModel::evaluate(double range, double frequency) const;
```

Fortran 两套 `sspMod` 只作为公式和行为参考，不进入 C++ 链接依赖。

## 9. 数值一致性策略

“复用结果等于逐频单跑”需要统一以下细节：

- 相同的发射角集合；
- 相同的几何积分步长；
- 相同的反射点和边界段选择；
- 相同的吸收积分权重；
- 相同的幅度终止语义；
- 每个频率独立调用 `PickEpsilon`；
- 每个频率独立调用 `ScalePressure`；
- 不共享会被前一个频率污染的模块级临时状态。

建议第一版先在无吸收、刚性/真空边界下验证几何和相位，再逐步加入复杂损失模型。

## 10. 错误处理与运行信息

宽带运行开始时应向 PRT 输出：

- `Nfreq`、最小/最大频率；
- 几何轨迹参考设置；
- 是否启用轨迹复用；
- 最高频率对应的推荐射线数；
- 压力场分配大小；
- 不支持选项检查结果。

建议分别计时：

```text
Geometry tracing time
Frequency reweighting time
Influence time
Output time
Total time
```

这能判断后续优化应继续针对声线积分还是 Influence。

## 11. 渐进实施建议

1. 先接通宽带输入、三维 `U` 和 SHD 输出，但暂时仍逐频完整追踪，建立正确的宽带基线。
2. 再引入几何轨迹复用，结果与该基线比较。
3. 最后优化数据布局和模块接口。

这种顺序可以将“宽带输出问题”和“复用算法问题”分开定位，降低一次性改动风险。
