# 02 射线理论与原 Bellhop 代码映射

## 1. 理论来源与使用原则

本项目指定 [06 射线轨迹方程以及动态射线追踪方程推导](./06-射线轨迹方程以及动态射线追踪方程推导.html) 作为二维射线理论参考。该 HTML 中已修订竖直慢度导数和动态方程符号问题。

实现时采用以下优先级：

1. 统一后的规范方程；
2. 原 Bellhop `Step.f90` 的数值离散行为；
3. 解析算例和单频回归结果；
4. HTML 中间推导的文字与排版。

修订后的关键方程已经与原 Bellhop `Step.f90` 逐项核对。实现仍以“规范方程 + 原代码离散行为 + 数值测试”三者一致为准，避免只按公式外观逐行翻译。

## 2. 规范符号

| 符号 | 含义 | C++ 建议命名 |
|---|---|---|
| `x=(r,z)` | 二维位置 | `position` |
| `s` | 中心射线弧长 | `arcLength` |
| `tau` | 程函/传播时间 | `travelTime` |
| `c(r,z)` | 实声速 | `soundSpeed` |
| `u=grad(tau)=(xi,zeta)` | 慢度向量 | `slowness` |
| `e_s=c u` | 单位切向 | `tangent` |
| `e_n=(c zeta,-c xi)` | 单位法向 | `normal` |
| `q` | 法向几何偏移基本解 | `q` |
| `p` | 法向慢度扰动基本解 | `p` |
| `c_nn` | 声速沿射线法向的二阶导数 | `soundSpeedNormal2` |

为避免混淆，C++ 中不要同时把声压和动态射线变量命名为 `p`。声压统一使用 `pressure`，动态变量可以保留 `p` 或命名为 `dynamicSlowness`。

## 3. 中心射线规范方程

由程函方程：

```math
|\nabla \tau|^2 = \frac{1}{c^2}, \qquad \mathbf{u}=\nabla\tau
```

得到以弧长 `s` 为参数的二维射线方程：

```math
\frac{d\mathbf{x}}{ds}=c\mathbf{u}
```

```math
\frac{d\mathbf{u}}{ds}=-\frac{\nabla c}{c^2}
=\nabla\left(\frac{1}{c}\right)
```

分量形式为：

```math
\frac{dr}{ds}=c\xi, \qquad
\frac{dz}{ds}=c\zeta
```

```math
\frac{d\xi}{ds}=-\frac{c_r}{c^2}, \qquad
\frac{d\zeta}{ds}=-\frac{c_z}{c^2}
```

几何传播时间满足：

```math
\frac{d\tau}{ds}=\frac{1}{c}
```

这些方程只依赖实声速及其空间导数，不显式依赖频率，是几何轨迹可复用的理论基础。

## 4. 动态射线规范方程

沿中心射线的近轴一阶系统为：

```math
\frac{dq}{ds}=cp, \qquad
\frac{dp}{ds}=-\frac{c_{nn}}{c^2}q
```

其中：

```math
c_{nn}=\mathbf{e}_n^T\,\nabla^2 c\,\mathbf{e}_n
```

原 Bellhop 同时积分两组基本解，因此 `ray2D%p` 和 `ray2D%q` 都是长度为 2 的数组，初值为：

```text
p = [1, 0]
q = [0, 1]
```

这不是二维空间分量，而是动态系统的两组线性独立解。C++ 数据结构应保留这个含义，不能误写成 `Vec2` 后当作空间向量运算。

## 5. 与 `Step.f90` 的逐项映射

| 理论量 | Fortran 表达 | 说明 |
|---|---|---|
| `x` | `ray%x` | `(r,z)` |
| `u=(xi,zeta)` | `ray%t` | 注释称 scaled tangent，实际为慢度向量 |
| `e_s` | `c * ray%t` | 单位射线切向 |
| `p,q` | `ray%p`, `ray%q` | 两组动态基本解 |
| `c_nn/c^2` | `cnn_csq` | 由 Hessian 和慢度方向计算 |
| `d x/ds` | `urayt = c * ray%t` | 对应位置推进 |
| `d u/ds` | `-gradc/csq` | 对应慢度推进 |
| `d p/ds` | `-cnn_csq*q` | 动态慢度推进 |
| `d q/ds` | `c*p` | 动态位移推进 |

`Step.f90` 采用带动态步长修正的二阶 polygon/modified Heun 方法。C++ 首版应复现它的离散顺序和边界落点逻辑，而不是一开始替换为通用 ODE 库；否则难以判断差异来自重构还是积分器变化。

## 6. `c_nn/c^2` 的代码形式

设慢度为 `u=(xi,zeta)`，法向为：

```math
\mathbf{e}_n=(c\zeta,-c\xi)
```

则：

```math
\frac{c_{nn}}{c^2}
=c_{rr}\zeta^2-2c_{rz}\xi\zeta+c_{zz}\xi^2
```

这正对应 `Step.f90` 中：

```fortran
cnn_csq = crr * t(2)**2 - 2*crz*t(1)*t(2) + czz*t(1)**2
```

该映射应写成独立、可单元测试的 C++ 函数。

## 7. HTML 修订结果核对

### 7.1 竖直慢度导数

修订后的 HTML 已将竖直慢度对应的声速导数统一为对 `z` 求导：

```math
\frac{dp_z}{d\sigma}=-\frac{1}{c^3}\frac{\partial c}{\partial z},
\qquad
\frac{d\zeta}{ds}=-\frac{1}{c^2}\frac{\partial c}{\partial z}
```

### 7.2 动态方程符号

修订后的 HTML 已将中间推导和最终动态方程统一为负号，与原 Bellhop `Step.f90` 一致：

```math
\frac{dp}{ds}=-\frac{c_{nn}}{c^2}q
```

当前理论参考与代码采用相同符号约定。后续仍需通过等声速解析解、有限差分动态射线和步长收敛测试验证离散实现。

## 8. 频率独立与频率相关边界

可复用的几何系统：

```text
position, slowness, dynamic p/q, real travel time,
boundary intersection, incidence direction
```

逐频状态：

```text
complex travel time, volume attenuation,
reflection amplitude/phase, epsilon, beam window,
complex pressure contribution
```

若实声速发生色散，或启用会改变反射点和 `q` 的 beam shift，则中心射线和动态射线本身变为频率相关，严格 ray reuse 不再成立。

## 9. 理论验收测试

- 等声速：射线为直线，`p/q` 有解析解。
- 线性声速梯度：检查 Snell 不变量和弯曲方向。
- 有限差分：用相邻发射角射线验证动态 `q`。
- Hessian 测试：用解析二次声速场验证 `c_nn`。
- 步长收敛：步长减半后误差应呈二阶收敛趋势。
- 频率复用：无色散环境下所有频率的几何路径应完全相同。
