1. 核心起点：亥姆霍兹方程 (The Helmholtz Equation)

射线声学的理论基础是笛卡尔坐标系 x=(x,y,z)\mathbf{x} = (x, y, z)x=(x,y,z) 下的频域声波方程，即亥姆霍兹方程：

  • ppp: 声压 (Acoustic pressure)
  • c(x)c(\mathbf{x})c(x): 空间分布的声速 (Sound speed)
  • ω\omegaω: 声源的角频率 (Angular frequency)
  • x0\mathbf{x}_0x0​: 声源位置
  • δ(x−x0)\delta(\mathbf{x} - \mathbf{x}_0)δ(x−x0​): 狄拉克函数，代表点声源
💡 在进行射线推导时，我们主要关注声源位置以外的声场传播规律。因此，在随后的代入过程中，我们通常令等式右边为 0（即重点关注齐次亥姆霍兹方程 ∇2p+ω2c2p=0\nabla^2 p + \frac{\omega^2}{c^2} p = 0∇2p+c2ω2​p=0）。

1.1 假设解的形式：射线级数 (The Ray Series)

为了求解上述偏微分方程，我们假设声压解具有以下特定形式，即射线级数：

  • τ(x)\tau(\mathbf{x})τ(x): 相位函数（也称为传播时间或程函，Eikonal），描述波前。
  • Aj(x)A_j(\mathbf{x})Aj​(x): 振幅函数（WKB近似，级数），描述波的能量分布。
  • 该级数通常是发散的，但在高频（ω→∞\omega \rightarrow \inftyω→∞）情况下，它可以作为精确解的渐近近似 (asymptotic approximation)。
